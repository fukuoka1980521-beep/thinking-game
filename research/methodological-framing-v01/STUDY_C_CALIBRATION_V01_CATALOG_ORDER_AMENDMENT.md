# Study C Calibration v0.1 — Pre-data Catalog-Order Amendment

Status: PRE-DATA CONFOUND CONTROL

Before any Study C calibration trajectory was generated, the visible catalog order in C2 was permuted so that abstract evidence roles do not appear in the same list positions as C1.

Reason:
If both worlds listed R1-R8 in identical order, a generic positional preference such as "open the first card" could transfer across worlds and be mistaken for a role-based evidence-selection signal.

Changed:
- C2 display order only.

Unchanged:
- module IDs;
- module contents;
- module descriptors;
- abstract role mapping;
- evidence budget;
- method conditions;
- path vector;
- classifier;
- permutation procedure;
- GO/NO_GO gate.

No calibration output existed when this amendment was made.
