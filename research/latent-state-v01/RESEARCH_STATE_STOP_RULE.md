# OLSR Research-State Stop Rule

Current state after v0.5 pre-data freeze:

`STOP_PRE_DATA_METHOD_EXPANSION / START_NATURAL_ACCUMULATION`

## Meaning

Do not keep adding statistical methods, features, taxonomies, or gates simply because the research infrastructure can be improved further.

The next valid progress is primarily:

1. ordinary authorized work continues;
2. a material event occurs naturally;
3. the event passes deterministic triage;
4. optional pre-existing matched control is selected;
5. validated prospective record is appended;
6. readiness remains ACCUMULATE_ONLY until the frozen checkpoint.

## Exception

A change before evidence accumulation is allowed only for:
- a protocol/implementation contradiction;
- a privacy/security flaw;
- a runtime defect that prevents the frozen protocol from executing.

A new interesting idea is **not**, by itself, an exception.

This rule is itself part of the protection against method drift and narrative overfitting.
