> **SUPERSEDED, KEPT AS REFERENCE ONLY, INCOMPLETE (self-critique pass was mid-revision when this
> Run's directive was replaced by `NEW_LIFE_CORE_REDESIGN_V1`).** Not implemented. The branch

> exactly the kind of fixed-scene-list shape the new directive forbids ("朝イベント→3択→午後イベ

> notes (silence, gesture, restraint) are a genuine register reference for how these 4 NPCs should
> sound, reused loosely in `NEW_LIFE_CORE_REDESIGN_V1`'s actual DAY1 implementation without

Written as a work, not a schema. No internal type names, no state-machine vocabulary. Each scene:
時間 / 場所 / 登場人物 / 状況 / 台詞 / 自由入力ポイント / 選択可能行動 / その場の結果 / 後日使え
る出来事. Player-facing choice labels are things a person would actually say — never "情報を確認
する"-style menu language.

Structure: each day has a **spine** (always happens) and a **branch point** (player picks between
Yohei/喫茶のどか/集会所, per the established Challenge Town five-location map — 仮住まい and 商店
街 are spine locations, not player-chosen). This screenplay writes the spine fully and writes ONE
full branch per day (the route that carries the 30-Day Draft's representative throughline —
Yohei, then Miyoko, alternating), with a compressed note for the other branches so the design is
provably not a single forced path, without writing three full scripts for every day.

### Scene 1.2 — チャレンジセンター、神谷との初回面談
**時間**: 朝〜昼前。**場所**: チャレンジセンター。**登場人物**: 主人公、神谷。
**状況**: 定型の説明（30日、いつでも相談可）の後、神谷がファイルを閉じながら本題に入る。
**台詞**:
> 神谷「ここがチャレンジセンターです。30日間、いつでも相談に来てください」
> （ファイルを机に置く）
> 神谷「一つだけ聞かせてください。あなた、本当は何がしたいんです?」
**自由入力ポイント**: 上記の質問に対する自由記述。神谷の口頭の返答は当たり障りのない範囲に留め
る（聞き飽きた質問である含みを持たせる）が、**ナレーションで一文だけ**：神谷がメモに書き込む内
容は、プレイヤーの発言そのものではなく、神谷なりの「分類」であることを匂わせる（説明しない。
「型にはめた」と書かない。メモを取る、それだけを描写する）。
**選択可能行動**: 自由記述のみ、選択肢なし。
**その場の結果**: 神谷「30日、短いようで長いですよ。まずは町を歩いてみてください」。
**後日使える出来事**: 神谷の「分類」はDAY5/15で本人が訂正する対象として内部的に保持（プレイヤ
ーには見せない）。

**状況**: 洋平が奥から出てきて、古い工具箱を持ち上げる。少し重そうに。

## DAY 2

### Scene 2.1 — 相馬の誘い（分岐点の一つ、集会所）
**時間**: 午前。**場所**: 集会所。**登場人物**: 主人公、相馬。
**状況**: 相馬が掲示板の古い貼り紙を剥がしている。特に用もなく寄った主人公にちらりと目をやる。
**台詞**:
> 相馬「働いてないの?」
> 主人公（プレイヤーの発言として）「今は」
> 相馬「へえ」
> （道具袋から軍手を取り出し、無造作に差し出す）
> 相馬「これ持って。午後、現場について来るか」
**選択可能行動**:
1. 「ついて行きます」
2. 「今日はやめておきます」
**その場の結果**:
1. 軍手を受け取る。→午後の現場同行シーンへ直結（Scene 2.2）。この日は他の場所を訪れない（機
   会費用——半日消費の主要な実例。テストで直接検証可能な性質）。
2. 相馬「そうか。まあ、気が向いたらな」。軍手を袋に戻す。→通常運行（他2箇所のうち1つを訪ねら
   れる）。
**後日使える出来事**: 1を選んだ場合、DAY3の「体が重い」、DAY3集会所訪問時の「昨日は助かった」
、以後の修繕系スレッド全体の起点。

### Scene 2.2 — 現場同行（分岐1を選んだ場合のみ）
**時間**: 午後。**場所**: 町内複数箇所（固定シーンとして一括表現）。**登場人物**: 主人公、相馬。
**状況**: 蝶番、水漏れの蛇口、二人でなければ運べない荷物——3件の小さな仕事。相馬は事前説明をし
ない。短い指示（「持って」「そっち」）だけで進む。
**台詞**: 最小限。移動の合間、脈絡なく一言：
> 相馬「にしても、何でこの町に来たんだ?」
**自由入力ポイント**: 上記への自由記述。相馬は深追いしない——「そうか」程度で流す（AIの返答が
多少的外れでも、相馬のキャラクターがそもそも深追いしない設計なので破綻しない、という設計上の
利点）。
**選択可能行動**: なし（自由記述後、継続のみ）。
**その場の結果**: 「相馬の現場に半日同行した」。
**後日使える出来事**: DAY3、DAY11、DAY23（祭り）に接続。

*（分岐2＝断った場合の圧縮ノート：この日は通常構造——2箇所訪問＋自由入力1回＋夕方＋夜。自由入

### Scene 7.1 — 集会所の屋根（スパイン、傍観）
**時間**: 午前。**場所**: 集会所。**登場人物**: 主人公、相馬（遠目）。

**台詞**: 屋根の上から、脈絡なく一言。

**自由入力ポイント**: 上記への自由記述。相馬は屋根を見たまま「ふうん」程度の相槌のみ——長い会
