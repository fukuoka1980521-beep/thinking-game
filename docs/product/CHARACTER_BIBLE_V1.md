> 存在しない点、店長と八百屋の大将の話し方が衝突している点、田村さんのVISUAL HOOKが
> 弱い点、CASE7/CASE9の新規人物が未設定のままの点が監査で判明した。ほっこりおじさんに
> ついても「事件へ巻き込まれる自然な理由」「本人なりの価値観」の欠落が指摘された。
> 詳細・修正方針は[`PRODUCT_AUDIT_V1_1.md`](./PRODUCT_AUDIT_V1_1.md) Section2〜4を参照。

`THINKING_GAME_PRODUCT_SPEC_V1.md`の`DELIVERABLE 2`。舞台はひだまり町（仮称、
`THINKING_GAME_PRODUCT_SPEC_V1.md` Section5）。既存アセット（`ossan-cheerful.png`/
`ossan-listening.png`、`src/data/companions.ts`の4体）を正式なキャラクター設計の土台として
採用し、`src/pilot/cases/case2.ts`/`case3.ts`にすでに登場している山本さん・田村さんを
正式な町の住人として引き上げる。人物を「○○タイプの人間」という固定分類にしない——
PLAYERが「この人ならこうしそう」と思える程度の一貫性は持たせつつ、状況・関係・目的・感情・
過去によって時々その予想が外れる（これがB＝人間観察・行動予測のゲーム性を支える）。

## 主人公：ほっこりおじさん

単なる問題文の主人公ではなく、IPキャラクター候補として設計する。完璧な善人にはしない。

| 項目 | 内容 |
|---|---|
| NAME | 未定（作中では「おじさん」と呼ばれ続けるが、正式名は将来のC拡張・IP展開のため予約しておく——現時点でSEASON1中に明かさない） |
| AGE RANGE | 60代後半〜70代前半 |
| ROLE | ひだまり町を長く歩き回っている、町の「顔なじみ」。特定の職業に固定しない（元は何かの仕事をしていたが、今は半分隠居・半分近所付き合いで日々を回している——詳細は将来のCASEで小出しにする） |
| VISUAL SILHOUETTE | 丸眼鏡・グレーの眉と口ひげ・紺のジャケットにベージュのマフラー（既存アセット2点で確立済み）。フェルト/ぬいぐるみ調のchibiプロポーション |
| COLOR/ITEM MOTIF | 紺（ジャケット）＋クリーム（マフラー）。常に小さな布のトートバッグを提げている——中身は町のCASEごとに変わる小物（パンの袋、忘れ物、写真等）を出し入れする「物語の受け皿」として機能させる |
| FIRST IMPRESSION | のんびりしていて、少しお節介。他人の事情に首を突っ込みがち |
| ACTUAL PERSONALITY | 実は観察がかなり細かい（ただし本人はそれを「特技」だと思っていない、自然にやっている）。人の変化によく気づくが、気づいたことをすぐには言わない——ためらってから動く |
| STRENGTH | 町の人のちょっとした変化（挨拶の調子、店の並びの違い）によく気づく。物腰が柔らかいので、人が本音をこぼしやすい |
| WEAKNESS | 思い込みで早合点することがある（勘違いする／面倒くさがる／失敗する、をSEASON1中に複数回起こす——CASE1の「余分なメロンパンを盗んだ疑いをかけずに済んだ」ような、疑わずに済んだ側面もあれば、逆に空回りする回もある） |
| HABIT | 気になることがあると、無意識にマフラーの端を触る。考え込むと「うーん」と声に出す |
| WAY OF SPEAKING | 敬語と砕けた口調が混ざる、やわらかい関西弁ではない標準語ベースの「ご近所口調」。相手を急かさない言い方（「まあ、ゆっくり考えよう」） |
| SECRET / UNKNOWN SIDE | 過去に町を離れていた時期があり、戻ってきた理由はSEASON1では明かさない（将来のC拡張・IP展開のためのフック） |
| RELATIONSHIPS | 町のほぼ全員と顔見知り。特に三日月珈琲のマスターとは長い付き合い（Section「町の主要人物」参照） |
| COMEDIC TRAIT | 些細なことで盛大に驚く（「あれ？」のリアクションが毎回大きい）。デジタル機器がやや苦手で、スマホの操作に手こずる小さなギャグを時々挟める |
| EMOTIONAL HOOK | 誰かのために動くとき、恩着せがましくない。CASE1のエンディング（研修中の店員に静かに事情を伝え、相手の失敗を大きくしない）がこの人物の核 |
| REAPPEARANCE VALUE | 全CASEの固定主人公。町のどのロケーションにも顔を出せる立場のため、新CASE・新ロケーションを開くたびに違和感なく再登場できる |

## PLAYER ROLE：事件簿係

| 項目 | 内容 |
|---|---|
| NAME | 名乗らない（PLAYER自身の分身ではなく、おじさんに同行する立場——`PilotIntroScreen.tsx`の既存文言「事件簿係」を正式な商品ロールとして採用） |
| ROLE | おじさんの隣で一緒に手掛かりを追う同行者。おじさんにはならない、おじさんの代わりに考えない——おじさんが実際にどうするかは物語側が決め、PLAYERは予想し、見届ける立場に徹する |
| RELATIONSHIP TO OJISAN | 「一緒に考える」関係。師弟でも上下関係でもない。既存`docs/DECISIONS.md`のPARTNER設計意図と一貫 |
| DESIGN NOTE | PLAYERの一人称的没入を強めすぎない——事件簿係は「観察者としての立ち位置」を保つことで、ENDINGでの内面断定禁止（Case Design Grammar #10）とも整合する |

## 同行相棒（Companions）

既存`src/data/companions.ts`の4体のロール定義は維持し、発言実装（`frameInsight`が
プレイヤー発言の要約に陥っている問題、PHASE3 storyboard Section09で特定済み）は商品原則
として是正対象とする（同じPLAYER回答を言い換えるだけの発言を禁止）。

| ID | 名前 | 見る場所 | SEASON1での位置づけ |
|---|---|---|---|
| DETECTIVE | 探偵 | 証拠・事実・矛盾 | CASE1から同行可能（固定） |
| OBSERVER | 観察者 | 人物・関係・表情・状況 | CASE1完了後にunlock（既存Pilot設計を継承） |
| DEVIL | あまのじゃく | 逆仮説・反例 | 将来候補（SEASON1では非表示のまま温存） |
| STRATEGIST | 作戦家 | 条件・次の一手 | 将来候補（同上） |

将来的には、同行相棒によって見つけやすい情報や会話の切り口が変わる余地を残す（例：観察者
同行時は人物の表情・態度に関する手掛かりが見つけやすい、探偵同行時は物証系の手掛かりが
見つけやすい）——これはSEASON1では実装しないが、CASE設計（`SEASON1_SCENARIO_BIBLE_V1.md`）
のCLUE分類をこの将来拡張に耐える形（物証／人物証言／状況証拠）で揃えておく。

RELATIONSHIP entityの初期値としては「常連客／旧友／近所／雇用関係／元同僚／情報のハブ」の
