dialogue/*,content/*}` directly (function-by-function, not by re-reading old CLOSE docs) as this
phase's own DISCOVER pass.

## Section 3 -- Zero Silent Gap Rule, applied

Every row marked "Conversation-relevant? = Yes" now has an explicit, named field in `NpcAiContext`
except row 11 (promise-kept positive acknowledgment), which is explicitly logged as a
NON-BLOCKING PRODUCT LIMITATION (Section 20) rather than silently assumed fine -- its absence
causes no contradiction (the NPC simply doesn't proactively mention it), unlike row 15/18 before
this phase's fix (where absence caused an *active wrong answer*). This distinction -- "the model
has nothing to say" vs. "the model says something false" -- is the actual line this phase draws
between BLOCKING and NON-BLOCKING.
