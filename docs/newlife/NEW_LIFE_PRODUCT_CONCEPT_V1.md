# NEW LIFE Product Concept V1

## Core concept
思考を整理し、自分で決め、行動に変える助けになる人生シミュレーション。

## Player promise
ゲームが正解を決めない。プレイヤーの自由入力が人・関係・状況を動かす。

## Core loop
出来事 → 会話・観察 → 自由入力 → NPC反応 → 状況変化 → 思考整理 → 自分で決断 → 行動 → 結果 → 振り返り

## Product rules
- 自由入力を主導線にする。選択肢は迷った時の補助。
- NPCは全員が賛成しない。立場・関係・記憶に従って反応する。
- 思考整理は任意。正解・点数・性格診断にしない。
- 整理するのは「大事なこと」「まだ分からないこと」「次に一つだけやること」。
- 成功だけを成長と扱わない。試す、断る、修正する、助けを求めることも行動。
- DAY 30は職業や資産だけでなく、DAY 1から考え方と行動がどう変わったかを振り返る。

## Current implementation step
既存30日候補を壊さず、自由入力を主導線として明示し、行動候補を補助へ降格。任意の「思考を整理する」パネルを追加する。

## Human gate
「プレイヤーがゲームに動かされたか」ではなく「プレイヤー自身が考えてゲーム世界を動かしたか」を観察する。
