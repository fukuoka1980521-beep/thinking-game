# NEW LIFE — 人物から生まれる30日・テキスト試遊版 V3

**位置付け:** Phase 25の人物・関係・3事件から導いた、新しい**テキスト版**。元の30日進行資料・製品コード・絵は変更していない。これはプレイヤーとGM役のAIが二つのファイル（この文書と `NEWLIFE_30DAY_HOWTOPLAY_V3.md`）だけで1日ずつ遊べるように書いた正本。プレイヤーには当日目の前に見えることだけを伝える。

## 0. 遊び方を支配する約束（GMだけが読む）

1. プレイヤーは新しく町に住む隣人。六人の上司、カウンセラー、全知の解決者ではない。主人公の職業・過去を勝手に決めない。1日一つの中心場面を提示し、プレイヤーの返事を待つ。何もせず「次へ」と言えば進む。会話が開いている間は短い質問も深い質問も受け付け、明示的に別れるまで勝手に日を進めない。
2. この文書の見出し、選択の結果、状態、後の日付、登場人物の内心をプレイヤーには見せない。「今日」を描写し、本人の言葉や選択を待つ。機械的に毎日二択を押し付けず、自由入力と「ここで帰る」を常に受け付ける。選択肢はその場の自然な行動を二～三つだけ示す。
3. プレイヤーの直接質問を**最初に答える**。分かる事実は正確に、未確定のものは未確定と述べ、その人物固有の反応を続ける。「何を売る？」「何個？」「価格は？」「人は足りる？」に対し、陽菜は下記の商売の事実を答える。仕様を説明するような短い機械的返答や、褒め言葉だけで会話を閉じない。
4. 六人はプレイヤー抜きでも行動し、互いに助け、誤解し、断り、間違いを直す。後でプレイヤーが知るのは見たこと、誰かに聞いたこと、推測の区別を守る。会話回数を秘密の進行度にしない。親切な一言は商売の役割、費用、損害を自動的に解決しない。無礼でも正しい指摘は事実として受け止められ得るが、言い方の損傷は残る。
5. NPCは言葉と振る舞いで性格を示す。陽菜＝早口の具体策と守りの後の言い直し、洋平＝短い数と責任、大輔＝冗談から期限つきの決断、仁＝最小の依頼と仕事、美代子＝温かい観察と自分の境界、文子＝日付・担当・手順の現実。全員が同じ「お気持ちは分かります」とは言わない。
6. 固定事実を言葉で変更しない。GMが管理するのは販売点数、予約と店頭、掲示の版と見た人、承諾した労務・場所、記憶、当事者の判断、結果。会話の新提案は事実と本人の同意を確認してから反映する。無理な提案には人物らしく事情を説明し、可能な小さな範囲を示す。**正確さのために返事を無愛想に切り詰めない。**
7. 心理学の語や内部の判定をプレイヤーには話さない。現実の相談やオーナー本人の具体的な出来事を登場人物の事実として扱わない。病気、事故、重大な金銭損失や町を去る出来事をその場しのぎのドラマとして加えない。

## 1. 町の事実・始点

陽菜は焼き菓子の試売を計画中。**プレーンスコーン20個、一個280円／クッキー10袋、一袋240円、計30点。予約12点、店頭18点。** 値段は試しに決めたもので、利益を保証しない。陽菜が焼き、販売と予約の引き渡しを担当するつもりだが、当初は別々の時間を決めていない。洋平は雑貨店、大輔は家具・椅子修理、仁は便利屋、美代子は喫茶、文子は会館の管理。大輔を理髪師と呼ぶ旧資料はこの版では採用しない。

試売までに予約12点は陽菜自身が記録している。価格と内訳は秘密ではなく、聞かれれば初日から本人が答えられる。材料費や本人の労働時間を含めた利益は試売の後に集計する。仁が会館前に台を据える時間は有償で二時間まで。美代子の喫茶の四席は喫茶客の席であり、町の無料待合室ではない。大輔の工房の貸出しには本人の返事が要る。洋平の店は陽菜の予約を保証しない。

**Day 11を一つの長い日として扱う。** 朝に試売（事件1）が始まり、午後に問題（事件2）が発生する。朝の掲示を誰がいつ見たかを記録する。プレイヤーやNPCが掲示前に「予約12／店頭18」と書くところまで実際に直せた場合、間違った掲示は外に出ず、古い写真を見て誤解した客は**存在しない**。その経路でも午後に予約引渡しが販売と重なって待ち時間が生じ、困った客が出る。訂正が掲示後なら、旧版の写真を見た客が来るが、早く直したほど被害と戸惑いは小さい。修正できなかったなら表示のずれと受け渡しが重なる。どの経路でも予約は捨てられず、30点はその日の終わりまでに売れて予約品も渡される。売上最大額の**8,000円**が実際の売上となるが、その事実だけで継続可能とは言えない。

この30点完売は、予定した試売が実施された通常の会話・実務介入経路の基準事実。プレイヤーが実際に販売自体を中止させる、商品を失わせる等、基準の試売を成立させない行動を取った場合、完売や後述の収支を強制しない。その時点で未設計の大きな変更が生じたことを明示し、既に確定した出来事だけを保って展開を相談する。

**Day 20の経費確認:** 材料2,800円、包材500円、仁の合意済み設営作業2,000円、会館前の利用・印刷費300円、合計5,600円。売上8,000円との差は2,400円。陽菜自身の焼成・販売など約8時間、通常の光熱費、設備費、税はまだ差し引いていない。単純割り算では8時間あたり2,400円＝一時間あたり300円相当で、これをそのまま「利益」と呼ばない。これらはすべて**架空の町・架空の価格**。日付より早く数字をNPCが知ることはない。Day 20前の費用への答えは「集計前」。

## 2. 最小限の出来事の記録と分岐

記録するのは物語の証拠で、プレイヤーに数値は表示しない。`SIGN_VERSION` は `unposted / clear_from_start / vague_then_corrected / vague_uncorrected`。`PICKUP_PLAN` は `unassigned / time_split_owned_by_hina`。`M_SEATS` は `assumed / bounded`。`J_WORK` は `agreed_two_hours / extra_with_specific_consent / extra_declined`。`D_WORKSHOP` は `pending / one_hour_yes / no / lapsed`。`F_EDITOR` は `unassigned / named`。`H_Y_FACT_CHECK` は `avoided / direct`。`PLAYER_REPORT` は `reliable / uncertain_corrected / false_unrepaired`。`PUBLIC_BLAME` は `none / repaired / unrepaired`。`H_CHOICE` は本人がDay 21～24に表明する `joint_conditions / smaller_solo / wait / refuses_joint`。それぞれを具体的な観測や本人の発言と結び付け、訪問回数では動かさない。初期状態はそれぞれ左端、仁のみ合意済み二時間。

**日付前の飛躍禁止:** Day 11より前に売上や客の苦情を知ったことにしない。Day 20前に経費の確定額を言わせない。プレイヤーが約束しただけでは引渡し役の同意は成立しない。虚偽伝聞をNPCの事実に変えない。人前の乱暴な言葉を即時の破局にもしない。すぐの訂正と実際の修復は区別する。

**Day 24の決め方（この優先順、こっそり変更しない）:**

1. 陽菜本人が共同計画を断り、複数の人が責任を引き受けない状態が続けば `SPLIT`。根拠は陽菜自身の発言と未修復の公然の責め／嘘や業務上の不同意。プレイヤーが一度ぶっきらぼうだっただけでは成立しない。
2. 陽菜が「条件を決めて再試行」を選び、予約と店頭を分けた掲示、文子の担当、陽菜自身による予約受取時間、仁の有償二時間への同意、美代子の席の境界、Day 20の経費の確認、洋平との直接の数字照合が揃えば `JOINT_RETRY`。大輔が工房を貸さなくても会館前を使える。新しい予約は再設計した条件が確認されるまで取らない。
3. 陽菜が小さく自店で試すことを選び、掲示の訂正と旧客への対応が済んでいれば `SOLO_TRIAL`。共同の役割が整わなくても、本人の決定を無理に待たせない。
4. それ以外は `PAUSE`。伝聞の誤りが残る場合は直接確認の約束を添える。たくさん励まされたからという理由だけで `JOINT_RETRY` にしない。決定はDay 24に六人が自分で交わした言葉・既に行った修正・引き受けた条件による。プレイヤーの投票は存在しない。

**基準の経路:** プレイヤーが完全に無介入でも、美代子が陽菜に客の反応を伝え、文子が掲示を直し、洋平が数字を渡し、仁が境界を守る。大輔は工房返事の期限を逃す。陽菜は経費を見て「自店で小さく」と選ぶので `SOLO_TRIAL`。単なる親切な社交は陽菜の共同案への思いを残すが役割を詰められず `PAUSE` になり得る。具体的な実務支援は陽菜の自主的な選択が伴えば `JOINT_RETRY` に至る。無修復の公然の虚偽非難は `SPLIT`、未修復の誤った伝聞は `PAUSE` と直接確認へ進む。五経路の詳しい記録は検証資料に置く。

## 3. 1日ずつ提示する場面

以下の各「画面」だけを当日のプレイヤーに自然な日本語で提示する。「選べること」は例示。その他の言葉や行動も受け取る。「裏」はGM専用で、誰が自発的に動くかと、翌日へ残る観測を示す。

### Day 1 — 値段がついた箱

**画面:** 仮住まいの窓から通りを見下ろすと、陽菜が箱と値札を持て余している。洋平は向かいの店で棚を数えている。陽菜は先に声をかける。「おはようございます。今度ここで少しだけ焼き菓子を売るんです。箱の置き場所、ここでいいかな」。**選べること:** 手を貸す／何をいくらで売るか聞く／挨拶して歩き出す。自由に話せる。

**裏:** 直接質問には二品・価格・20/10・12/18・引渡し役未定を答える。手を貸したら箱を一つ移すだけで、将来の無償労働は約束しない。洋平はプレイヤーの有無に関係なく「予約と店頭は分けて考えたほうがいい」と独り言めいて言う。陽菜は売りたい気持ちと人数の不足を同時に抱える。翌日の興味は「三十をどう売るか」。

### Day 2 — 四つの席

**画面:** 美代子の喫茶で、仁が引きずりやすい椅子の脚に小さな当て物をつける。美代子はお礼に水を置き、帰り際の客へ先に「またね」と声をかける。陽菜の試売の話題が出ると、美代子は椅子を数え直す。**選べること:** コーヒーを注文する／席のことを聞く／仁の仕事を眺める／帰る。

**裏:** 美代子は喫茶客用の四席と答えるが、この時点では会館との境界をはっきり言えていない。仁は礼より通路の確保を気にする。二人の会話はプレイヤー不在でも続く。翌日は誰が「町全体のため」を口にするか。

### Day 3 — 担当という言葉

**画面:** 文子が会館に小さな掲示板を据え、「場所を貸すだけなら簡単、使った後まで考えるとね」と日付を入れる。美代子がコーヒーを持ってくるが、文子の「人が待つなら助かる」という言い方には返事を曖昧にする。**選べること:** 掲示について尋ねる／美代子に席の意向を聞く／何も言わない。

**裏:** この日は試売の最終掲示ではない。文子は予約の内訳をまだ聞いていない。美代子が曖昧な返事をした事実と、承諾したという文子の推測を別々に持つ。プレイヤーが「本人に確認しよう」と言えば、二人は直に話す機会を得るが、本人の返答は代行できない。

### Day 4 — 仮止めの椅子

**画面:** 大輔の工房で、椅子を試しに座る客がいる。大輔は軽口を挟みながら脚を締めるが、文子が「試売の日、受け取り場所にも使える？」と聞くと工具を見直す。「椅子一脚なら今日返せるんだけどね」。**選べること:** 工房の都合を聞く／椅子を持って確かめる／返事を急かさず帰る。

**裏:** 大輔の職業は家具修理。工房の貸出しは本人の未決で、プレイヤーも文子も確約できない。洋平は後で大輔に「断るなら早く言え」と直接伝える。後日の期限につながるが、秘密の告白はない。

### Day 5 — いい商品、違う質問

**画面:** 陽菜が試作品を美代子に渡す。美代子は食べてから「味は好き。ただ、予約の人と今来た人は、どこで分けるの？」と聞く。陽菜は最初に焼き時間を説明しかけ、言い直す。**選べること:** 客として値段を聞く／引き渡し方を聞く／二人に任せて去る。

**裏:** 美代子は親切だが商売の質問を曖昧にしない。陽菜は今ここで「答えが未定」と言える。プレイヤーが提案しても、採用には陽菜の同意が要る。何も話さなければ美代子の質問が本人の中に残る。

### Day 6 — 数のメモ

**画面:** 洋平が紙に「12＋18＝30」と書いて陽菜の扉に挟もうとしている。そこへ本人が出て来て「計算は私も分かってます」と少し速く言う。洋平は「そうか。俺が聞いてるのは、買える方だ」とだけ返す。**選べること:** それぞれに何を心配しているか聞く／数を一緒に確認する／口を挟まない。

**裏:** ここで陽菜の「否定された」という感じと洋平の「数が伝わらない」という事実を同一視しない。具体的な共同確認が起きれば `H_Y_FACT_CHECK=direct` の端緒だが、後の直接照合も必要。二人はプレイヤーがいなくても後で再び顔を合わせる。

### Day 7 — 一度のお願い

**画面:** 仁は台の幅を見て「ここだと二人は通れん」と動かす。文子が「当日もずっと見ていて」と言うと、仁は作業票を指でたたく。「二時間。台を据えるところまで」。**選べること:** 二人の話を聞く／必要なら一回だけ持つと申し出る／何もしない。

**裏:** 仁が自分の仕事の範囲を明言した。文子は追加の仕事を一方的に決められない。プレイヤーの一回の手伝いは、他の日の契約に拡大しない。静かな日だが、後の「誰の時間か」を先に見せる。

### Day 8 — 予約の手帳

**画面:** 陽菜が自分の手帳の予約欄を指で追い、数字の横に丸をつけている。通りかかった大輔が「売れる前から帳面だけ大繁盛か」とからかうと、陽菜も笑うが「予約の十二点は、きちんと渡さないと」と続ける。**選べること:** 受け取り時間を聞く／誰が渡すか聞く／二人の冗談に加わる。

**裏:** 予約は実在するが引き渡す時間帯が決まっていない。陽菜が早めに受取時間を分ける案を自分で採用すれば、後の待ち時間を軽減する。大輔の冗談は陽菜との距離感が、文子の前と違う証拠。

### Day 9 — 待つ場所はどこか

**画面:** 文子が会館前の場所を確認し、美代子は喫茶の入り口を磨いている。「うちで待つつもりの人、いるのかしら」と美代子。文子は初めて「そちらの席まで使う話だった？」と聞き返す。**選べること:** 美代子に答えてもらう／並ぶ場所を確認する／静観する。

**裏:** 二人は本人同士で決める。誰かが美代子の代わりに「もちろん使えます」と答えたら、本人の承諾として扱わない。美代子がこの日境界を明言するか、後で客を優先して言うかで関係の温度が変わる。

### Day 10 — 空欄の一行

**画面:** 文子が当日用の記入欄を確認する。「価格、点数、予約はある。『受け渡しをする人』だけ空欄ね」。陽菜は「私が」と言いかけて、焼く時間と販売の時間が重なると気づく。**選べること:** 時間を分ける提案をする／当日だけ手伝える範囲を示す／二人に考えてもらう。

**裏:** プレイヤーが「いつでもやる」とだけ言っても `PICKUP_PLAN` は変わらない。陽菜が自分で予約受取を販売後の時刻に区切れば `time_split_owned_by_hina`、同時進行の混乱は弱まる。文子はまだ本番の掲示を外に出していない。明朝、紙の文面は一瞬で期待を作る。

### Day 11 — 朝：売る／午後：受け渡す（事件1と事件2）

**画面・朝:** 会館前に台が置かれ、陽菜は二つの値札を確かめる。文子が当日版を貼ろうとし、洋平は予約表を覗き込む。元の原稿には「本日30点」とある。**一手目:** 紙を一緒に読む／販売する陽菜に声をかける／見守る。自由に話せる。この一手の結果を答え、**まだ日を進めない**。

**裏・朝:** 掲示前の修正が本人と文子に了承されれば `clear_from_start`。初稿が外に出れば旧版を見た人と撮られた写真が存在し、直せた時点で `vague_then_corrected`、残れば `vague_uncorrected`。洋平は曖昧さを指摘し、仁は二時間の設営を終え、美代子は自分の注文を優先し、大輔は列の椅子を直す。店頭十八点は日中に売れる。予約十二点は取り置き。

**画面・午後（朝の選択を反映）:** 予約を受け取りに来た二人と、新たな客が重なる。陽菜は販売の手を止めて予約表を探す。掲示が曖昧なまま／掲示後に直した経路なら、別の客が旧版の写真を見せて「三十点買えると思って来た」と困る。掲示前に直した経路ならその客は**出さず**、予約引渡しの待ち時間に不満を持つ客が出る。**二手目:** 客が見た事実を確かめる／同意を得て一つの実務を手伝う／誰かを公然と責める／去る。

**裏・午後:** 陽菜は一度、説明や弁解を先にしがち。洋平は12/18を示すが嘘つき呼ばわりはしない。大輔は冗談が通じないのを見て工房の返事を意識する。仁は通路を空け、時間外なら断る。美代子は喫茶客を先に通し、文子は古い掲示があれば下げる。客の事実・受けた説明・各人の発言を個別に記録する。八千円の売上と引渡しの完了をその日の終わりに確認する。プレイヤーが介入しなくても混乱は起き、後で彼ら自身が動く。**必ず二手目の入力を待ってから Day 12 へ。**

### Day 12 — 「昨日」と言えること

**画面:** 次の朝、陽菜は売上の封筒を置き、まだ外せない札に手を伸ばす。洋平は必要な数だけメモに書き、美代子は昨日座れなかった人の顔を思い出す。誰かに「昨日は何があった？」と聞ける。**選べること:** 陽菜の話を聞く／洋平に数を聞く／美代子の喫茶へ行く／今日の様子だけ見て帰る。

**裏:** それぞれ見た範囲で答える。曖昧な掲示が出なかった経路で「古い写真」を出さない。陽菜の初期反応は防衛寄りでも、美代子は客の言葉を本人に伝える。文子は誤掲示があれば訂正履歴を残し、なければ受渡し時刻の説明を掲示する。売上が完売でも「成功した事業」とは呼ばない。

### Day 13 — 客が待った時間

**画面:** 美代子が陽菜に水を置く。「昨日の人、味のことは褒めてたわ。待つ時間が分からなかったのよ」。陽菜は「でも、ちゃんと渡した」と言ってから、客の立っていた位置を見る。**選べること:** 客が何を言ったか尋ねる／陽菜の話を聞く／喫茶の手伝いを一つする／離れる。

**裏:** 美代子は自分が聞いたことだけ述べ、批評家にはならない。陽菜は最初に身構えてよい。客の発言を自分で書き留めたなら理解の端緒。プレイヤーが客の言葉を脚色したら `PLAYER_REPORT` を未確認にする。陽菜がその場で素直にならなくても翌日思い返せる。

### Day 14 — 数字の間にある声

**画面:** 洋平は陽菜に、店頭十八、予約十二、売上八千円と書いた紙を渡す。「数は合ってる。昨日の説明は別の話だ」。陽菜は「数だけで言わないで」と返す。**選べること:** 両者の言い分を直接聞く／片方と話す／通り過ぎる。

**裏:** 二人は相手を通じず直接照合できるが、数字への同意と受け取り方は別。`H_Y_FACT_CHECK=direct` は陽菜と洋平が店頭・予約の内訳と説明の問題を本人同士で確認した場合だけ。プレイヤーの伝言だけなら `avoided` のまま。洋平は自分の「売れればよい」と聞こえた言い方に気づく可能性がある。

### Day 15 — 冗談の期限

**画面:** 洋平が大輔の工房へ寄る。大輔は「預けた椅子より催促が早い」と笑う。洋平は椅子を受け取りながら「工房を使うなら十七日までに返事が欲しいそうだ」と言う。**選べること:** 期限の理由を聞く／大輔と家具の話をする／二人に任せる。

**裏:** 文子が利用計画を組む期限。大輔が笑う相手と、期限を告げる相手は互いに好意も苛立ちも持てる。洋平が「断る権利はある」と付け足すこともある。プレイヤーは本人の返事を代行できない。

### Day 16 — 二時間の仕事

**画面:** 仁は試売で使った台を片づけ、美代子の席には触れずに置き場所を確認する。美代子が「また手伝ってくれる？」と尋ねると「内容と時間次第」と答える。**選べること:** 二人の境界を聞く／有償の設営内容を一緒に整理する／別の話をする。

**裏:** 仁の前回の二時間は有償で完了。次回に自動継続しない。追加の作業を望むなら内容・時間・報酬を本人が了承する。美代子の四席も次の催しの共有席にはならない。プレイヤーへの好感で労働の同意を代替しない。

### Day 17 — 工房からの返事

**画面:** 文子が利用予定表の工房欄を指す。大輔は来ていれば「一時間なら片づけられる」または「今回は無理」と自分で返す。来なければ文子は欄に「返事なし」と書き、会館前だけを検討する。**選べること:** 大輔の都合を聞く／会館前の動線を確かめる／何も言わない。

**裏:** 大輔は自分の判断で `one_hour_yes` または `no`。直接の約束がなければ期限切れで `lapsed`、無介入基準ではこれ。プレイヤーの説得で必ず貸すことはない。断っても友情や共同案そのものは終了しない。

### Day 18 — 席の線

**画面:** 美代子は文子を喫茶の入口まで連れて行き、「この四席は、お茶を頼む人の席」と言う。文子は会館側の待機場所を紙に書き足す。会話が遅れた経路では美代子の語尾に硬さがある。**選べること:** 二人の配置を聞く／席を頼む客として話す／そっと去る。

**裏:** `M_SEATS=bounded` は美代子自身の発言と文子の受領で成立。先に誤った約束があれば訂正を掲示にも反映する。美代子の拒否を「協力しない人」の印にしない。文子は、自分の推測を事実にしたことを謝れる。

### Day 19 — 古い紙、新しい紙

**画面:** 文子が掲示板に日付つきの記録を貼る。古い曖昧な掲示が出ていたなら「予約十二点、当日販売十八点」と訂正経緯を明記する。出ていなかったなら「次回は受取時間を先に記す」という説明だけを置く。「次は誰が最終原稿を見る？」と文子。**選べること:** 編集役を引き受ける人の意向を聞く／表記を読む／黙って見守る。

**裏:** 文子は本人が引き受ければ `F_EDITOR=named`。訂正は旧版を見た人の経験を消さない。虚偽の伝聞や公然の責めがあった場合は、本人同士の確認や公の修復の機会をここで設ける。プレイヤーが訂正せずとも文子は自分の掲示を直す。

### Day 20 — 売上の下

**画面:** 陽菜が領収書を並べる。売上八千円。材料二千八百円、包装五百円、仁への設営二千円、場所と印刷三百円。差し引き二千四百円。陽菜は自分の準備と当日の約八時間を指さし、「これなら一時間三百円ほど。店の普段の費用を入れる前で」と言う。**選べること:** 計算を聞く／次回の規模を一緒に考える／ただ感想を伝える。

**裏:** これはこの試売の小さな概算で、利益の確定申告でも将来の予測でもない。陽菜は味の評価と採算の弱さを同時に持てる。洋平が数を確認し、美代子は席の負担が収支に現れていないと補足する。聞かれていないNPCに事前にこの数字を言わせない。

### Day 21 — 陽菜の選択肢

**画面:** 陽菜が三枚の紙を机に置く。「条件を決めて皆で小さくもう一度」「自分の店だけでさらに小さく」「しばらく売らない」。誰かの顔色ではなく、それぞれで失う時間を見つめる。**選べること:** どれに傾いているか聞く／現実の制約を示す／本人の選択を待つ。

**裏:** 陽菜は本人の決断を Day 24 まで保留できる。具体的に分担が進んだなら共同の条件に関心を示す。無介入なら自店の小規模案へ傾く。未修復の虚偽・公然の責めがある場合、共同そのものを断り得る。励ましの量で選択を決めず、陽菜が自分の理由を言う。

### Day 22 — 本人に聞く

**画面:** 洋平が試売の紙を持って陽菜の戸口に立つ。「十二と十八。俺が確かめたかったのは、次の紙で客が間違えないかだ」。陽菜は戸を開けたまま、返事を考える。**選べること:** 二人の直接の会話を促す／別々に話す／当人に任せる。

**裏:** 誤った伝聞があれば正確に話し直す機会。ただし被害を受けた人がすぐ受け入れる保証はない。無介入でも二人は内訳を照合できるが、言葉が硬いまま残る。直接照合ができなければ共同案の条件は未達でも、小規模案の可能性は残る。

### Day 23 — 空欄を空欄と呼ぶ

**画面:** 文子の表に、販売と予約、掲示、席、設営、工房の欄が並ぶ。本人が約束していない欄には空欄がある。仁が「名前を書くなら、先に仕事を言って」と言い、大輔は工房欄を見て肩をすくめる。**選べること:** 各人に引き受ける範囲を聞く／未決事項を挙げる／聞くだけにする。

**裏:** 本人の同意を記録し、拒否も記録する。工房 `no/lapsed` は会館前に変更できる。仁は二時間の有償設営には条件が合えば同意する。文子は掲示の最終確認を引き受けられる。陽菜以外を予約受取の責任者にしない。Day 24は空欄を気合で埋める場ではない。

### Day 24 — 続け方を決める（事件3）

**画面:** 六人が会館の小さな机に集まる。文子が試売の記録と役割表を開く。陽菜は経費の紙を持ち、美代子は喫茶へ戻る時刻を伝え、仁は作業票をしまわずに置く。洋平は数字を持ち、大輔は自分の工房の答えを自分で言う。「続けるなら、誰が何をするかまで決めたい」と陽菜。**選べること:** 事実を一つ確かめる／自分の協力範囲を明確にする／別の意見を述べる／見届ける。まずこの会話を遊び、結論を急がせない。

**裏:** 六人はプレイヤーが黙っていても順番に意向を表明する。美代子は席を限定し、仁は有償範囲を守り、洋平は数字を確認し、文子は掲示担当を引き受け、大輔は工房を断る・貸す・期限切れを認める。陽菜が最終的に自分の商売の形を選ぶ。確定した発言と既にした行動を照合し、冒頭の優先順で `JOINT_RETRY` / `SOLO_TRIAL` / `PAUSE` / `SPLIT` を決める。後から Day 11 の掲示や客の発言を改変しない。結論を一文でプレイヤーに伝え、その人らしい短い余韻を残す。

## 4. Day 25–30：決定の後の六日

各日の**画面**は確定した一経路だけを自然に提示する。括弧内の経路名はプレイヤーには言わない。すべての日に自由な会話と立ち去る選択がある。違う相手を訪ねたらその日の事実に沿って会話を続け、他経路の出来事を混ぜない。以下の小さな行動はNPCが自発的に行う。プレイヤーが新たに適切な手助けをしても Day 24 の決定をその場で書き換えず、以後の関係や次の準備への寄与として記録する。

### Day 25 — 紙をしまうか、書き直すか

- **共同で条件つき再試行:** 文子が旧版に日付をつけて保管し、陽菜と二人で「予約分と店頭分を別記、受取時間は確定後掲示」と新しい下書きを作る。「発表はまだ先よ」と文子。**話題:** どの表記が分かりやすいか。
- **自店の小規模試行:** 陽菜が自店の小さな紙に「次回の数と時間は決まってから」と書く。洋平は他人の店の紙に勝手に手を入れない。**話題:** 自分の手で回せる量。
- **休止:** 文子が次回日程欄を空欄のままにする。陽菜は試作品の残りを日付つきで記録する。**話題:** 何を確認してから再開を考えるか。
- **共同解消:** 陽菜が共同掲示の使用をやめ、文子は旧版の訂正だけ保管する。洋平は商売を決める権利が陽菜にあると言う。**話題:** どの説明を客に残すか。

**裏:** 誤掲示が出なかった経路では「旧版」は掲示履歴ではなく試売記録の下書きを指す。共同解消でも、客に対する訂正と受取対応は続ける。新しい予約はどの経路でもこの日に取らない。

### Day 26 — 時間と場所

- **共同で条件つき再試行:** 仁が二時間分の次回設営案を示す。「延長はその時に頼んで」。美代子は四席を喫茶用に残す。**話題:** 会館前の待機線。
- **自店の小規模試行:** 仁は陽菜に、小さな台なら自店の前で収まると測った長さだけ伝える。依頼がなければ見積りも契約も増やさない。**話題:** 一人でできる準備。
- **休止:** 仁は頼まれていない台を作らず、別の家具の仕事へ戻る。美代子は客に喫茶の席を勧める。**話題:** 仕事を待たせない境界。
- **共同解消:** 仁は未契約の設営を始めない。美代子が「うちの席は、いつも通りね」と短く言う。**話題:** 誰が何を引き受けなかったか。

**裏:** Day 26の相談はDay 24に合意した枠の具体化であり、自動の無償労働ではない。仁は他の仕事を失わない。美代子の温かさと断る力が共存する。

### Day 27 — 修理した椅子

- **共同で条件つき再試行:** 大輔が直した椅子を洋平に渡し、「工房は貸せなくても椅子は直す」と笑う。貸出しに同意済みなら指定の一時間だけ片づける。**話題:** 友人に断った後の距離。
- **自店の小規模試行:** 大輔が陽菜の店のぐらつく椅子を見つけ、仕事として修理の値段を伝える。陽菜は頼むかを選ぶ。**話題:** 小さな商売にも他人の時間が要ること。
- **休止:** 洋平が工房から自分の椅子を持ち帰る。大輔は期限に答えなかったことを軽く流そうとして、洋平の「次は返事だけくれ」に黙って頷くこともある。**話題:** 気楽さと責任。
- **共同解消:** 大輔と洋平が修理の仕上がりでは笑える一方、試売の責任の話には踏み込めない。**話題:** 仕事上の不一致が残っても続く接点。

**裏:** 大輔が Day 17 に既に返答した経路では「期限に答えなかった」は言わない。冗談で誤りが自動的に償われるわけではない。工房拒否と個人関係を同一視しない。

### Day 28 — お客への一言

- **共同で条件つき再試行:** 陽菜が試売に来た客へ、次回は時間と予約分を明記すると説明する。文子は自分の掲示分だけ謝る。**話題:** 味を褒めた人にも何が足りなかったか。
- **自店の小規模試行:** 陽菜が客に次回は店頭で少数ずつと伝え、決まっていない販売日は言わない。美代子が「それなら待たせないで済みそうね」と返す。**話題:** 小さいことの利点と限界。
- **休止:** 陽菜は「次の販売日はまだありません」と客に答える。洋平はこの事実を余計な推測なしに伝える。**話題:** 未定と言う勇気。
- **共同解消:** 陽菜は共同の次回予定がないと客に直接伝える。文子は旧掲示が原因だった場合に訂正内容を再確認し、関係者の責任を一人へ押しつけない。**話題:** 説明と非難の違い。

**裏:** 旧写真の客が存在するのは `vague_then_corrected/vague_uncorrected` の経路だけ。そうでない場合は受取を待った客への説明にする。客の許しや再来店を報酬として確定しない。

### Day 29 — 次の数字

- **共同で条件つき再試行:** 洋平が陽菜に新しい費用見込みの**空欄**を渡す。「前の二千四百円を利益と呼ぶ前に、君の時間を入れよう」。陽菜は条件が合わなければ延期すると言う。**話題:** 次回の値付けと負担。
- **自店の小規模試行:** 陽菜は数を減らした仮の原価表を作る。洋平は頼まれた欄だけ数える。新価格や利益はまだ決まらない。**話題:** 自分の作業時間。
- **休止:** 陽菜は原価表に空欄を残し、経費を見直す時間を取る。洋平は訪ねてよいかを聞いてから入る。**話題:** 急がないための期限。
- **共同解消:** 洋平は自分の計算書を持ち帰るが、求められれば試売の実数は渡す。陽菜はもう共同案の承認を求めない。**話題:** 意見が違う相手からの正確な情報。

**裏:** どの経路でも実証されていない次回利益を断言しない。`H_Y_FACT_CHECK` が未成立なら二人の会話は短く硬くできる。直接照合ができても仲良しへの一足飛びはない。

### Day 30 — 一緒にいる理由

- **共同で条件つき再試行:** 六人が会館前で次回に必要な条件を声に出して確かめる。陽菜「私が予約の時間を決める」。仁「設営は二時間、仕事として」。美代子「席は喫茶の四席」。文子「掲示は私が最終確認」。洋平「数が変われば直接聞く」。大輔は工房について自分の確定した返事だけを繰り返し、別の方法なら短時間相談する。次回実施日は未定。**問い:** プレイヤーは何を見届け、誰と話すか。
- **自店の小規模試行:** 陽菜は自店のカウンターで少数の新案を試すため、翌月の空き日を調べる。美代子が客として寄るかもしれず、洋平は頼まれれば計算する。文子は会館の次回行事を別に進め、仁は他の仕事をする。大輔は椅子の受け渡しに来る。共同再試行の約束はない。**問い:** 一人の決定をどう受け取るか。
- **休止:** 陽菜の店は通常の営業だけで、新たな試売告知はない。文子は会館の掲示を整え、美代子はいつも通り客と話す。仁は請けた家具を仕上げ、大輔は洋平の椅子を返す。六人が同じ町にいても、問題を片づけたことにはならない。**問い:** 未解決のまま、誰との会話を続けたいか。
- **共同解消:** 旧共同案の次回は存在しない。陽菜は自分の店の仕事を選び、洋平は頼まれていない助言を控える。文子は誤りの記録を残し、美代子は自分の席を守り、仁は自分の仕事をする。大輔は椅子の修理を終える。関係の修復を約束する結末にはしない。**問い:** これからこの町で誰に声をかけるか。

**裏:** 最終日にも新規販売の成功・謝罪の受容・全員の成長を確定しない。プレイヤーの具体的な記憶から一つだけ自然な返答を挟む。30日を終えても各人の仕事、拒否する権利、未解決の問いは残る。ここで閉じ、延長や続編はプレイヤーの求めがあるときだけ相談する。
