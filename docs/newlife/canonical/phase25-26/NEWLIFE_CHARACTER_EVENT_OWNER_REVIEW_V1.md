# NEW LIFE — この6人と30日過ごしたいか

オーナー確認用・人物と事件の提案。**今あるゲームの30日分を書き直したものではありません。** 原本も画面も変更していません。ここで見てほしいのは「この人たちの次の行動が気になるか」です。

## 1. ゲームの核 — 一ページで

プレイヤーは、同じ通りに越してきた近所の人。小さな焼き菓子の試売をきっかけに、6人が同じ仕事に少しずつ関わる。最初は三十点を売るだけの話だった。十二点は予約、店頭に並ぶのは十八点。ところが掲示は「本日30点」。その写真を見て来た人と、実際に買える数の間にずれが生じる。

問題は三十点という数字そのものではない。**誰が最初の掲示を見た人に説明するのか。店主が焼いている間に予約品を誰が渡すのか。喫茶店の席や、便利屋の時間を誰の判断で使うのか。** 六人とも正しい部分と見落としがあり、同じ出来事でも行動が違う。

その後、「もう一度一緒に試す」「規模を縮めて一人で試す」「数を調べるまで止める」「共同の仕事を解く」という結末があり得る。プレイヤーは売り手の上司でも、町の相談員でもない。買ってもいいし、具体的な一時間だけ手伝ってもいい。強く反論して、関係を悪くしてしまうこともある。何もしなくても、洋平は数を調べ、文子は掲示を直し、美代子は自分の席を守れる。ただし、そのやり方と結果は変わる。

この設計の狙いは秘密を六つ集めることではない。**次に何が起きるか**を、人が自分で決めるまでの遅れ、言い損ねた境界、予想外の行動から生む。陽菜に「何を売る？ 何個で、いくら？ 人は足りる？」と聞けば、具体的に答える。数字がまだ出ていない経費は「分からない」と答える。口数が少ない人も、その後に何かをしている。会話は町の行動や記憶につながる。

**現状の正直な評価:** 元資料は分岐と出来事を丁寧に用意している一方、人物の自発性と会話への興味はオーナーの実地プレイで足りなかった。特に「何を売るのか」への返答を人物任せにしても、商売の事実が薄いままでは面白くならない。本案はその欠落を埋める**設計仮説**。実際に30日過ごしたくなるかは、まだ人間の試遊で証明していない。

## 4. 三つの出来事と、六人の反応

**出来事1 — 小さな試売。** 陽菜はスコーン二十個（一個280円）とクッキー十袋（一袋240円）を準備。合計三十点のうち予約十二点、店頭十八点。大規模な祭りではない。売上総額だけでは利益を判断できず、材料費・時間の集計はこれから。

| 人 | その日、自分からすること |
|---|---|
| 陽菜 | 値札を作り、誰が受け渡すか決めないまま一人で売り始める。 |
| 洋平 | “30点”を見て「店頭は何点か」と聞き、自分の店の約束と区別する。 |
| 大輔 | 列の椅子を直す。工房を次に使うかの返事は先送りする。 |
| 仁 | 決めた時間だけ台を置き、通路を確保して帰る。 |
| 美代子 | コーヒーと率直な味の感想を出し、喫茶の席が埋まるのを見る。 |
| 文子 | 日付入りの掲示を出す。承認の手続と読みやすさの違いにはまだ気づかない。 |

**出来事2 — 期待と現物がずれる。** 古い「本日30点」の写真を見た客は店頭分を三十点と思った。予約十二点が含まれることを知り、足を運んだのに買えない。予約客二人が同時に来るが受け渡し担当はいない。早めに掲示を直していれば影響は小さいが、古い写真は残る。けが・大損害・悪人探しにはしない。

| 人 | 最初の反応 → 次にあり得る行動 |
|---|---|
| 陽菜 | 「合計は三十」と説明して守りに入る → 客の見た文面を聞き、店頭十八と書き直すか、まだ言い訳する。 |
| 洋平 | 予約と店頭の数字を示す → 正しかったと突き放すか、数の分け方を手伝う。 |
| 大輔 | 一度冗談を言うが笑いがない → 工房を一時間貸すか貸さないか期限内に答える。 |
| 仁 | 人の通り道を空ける → 手押し車を一台借りるか、追加仕事を断る。 |
| 美代子 | 自分の客の注文を先に出す → 待合として席を使わせないと文子に伝える。 |
| 文子 | 最初は承認の手順を説明する → 古い紙を下げて訂正し、連絡担当を決める。 |

**出来事3 — 次を続けるか。** 一度謝れば解決、ではない。予約表示、受け渡し、席、作業代、材料費の見積もりを揃えて判断する。

|---|---|

## 5. 話しかけたときの手触り

**プレイヤー「何を売るの？　人は足りてる？」** 陽菜「スコーン二十個とクッキー十袋。十二点は予約で、店頭は十八点です。私が焼いて売るので、受け渡し係はまだいません。そこは、足りていないと思います」。これは実際のオーナープレイで必要になった返答の例。知らない利益は作り話で埋めない。

**プレイヤー「何か困ったら声をかけて」** 陽菜「ありがとう。……今は一つだけ。『30点』だと、店頭に何点あると思う？　さっきから、それが気になってる」。礼だけで会話を閉じず、自分がいま引っかかっていることを言う。プレイヤーが答えなくても美代子に聞ける。

**プレイヤー「この表示、おかしくない？」** 洋平「おかしい。予約十二、店頭十八。あの子の腕の話はしてない」。文子「私が通した掲示です。まず古い紙を下げる。新版を誰が書きますか」。同じ指摘で二人の仕事と責任の取り方が異なる。

**プレイヤー「手伝おうか」** 仁「この一往復、右側を持ってくれ。終わったら、もう頼まん」。美代子「ありがとう。今は注文を先に出すの。ここを待合にはできないわ」。申し出が必ず親密な会話に変換されるわけではない。

**プレイヤーが誰にも話しかけない** 場合でも、美代子は席のことを文子に伝え、文子は掲示を訂正し、洋平は数のメモを置く。大輔が返事を延ばせば工房は使えなくなる。町はプレイヤーの承認を待たない。

## 6. 同じ出来事から生まれる五つの行き先

| プレイヤーのふるまい | 町の選択 | 人間関係の残り方 |
|---|---|---|
| たくさん励まし、全員と話すが数を詰めない | **一度停止**。担当と経費が決まらない | 親しさはあっても陽菜と洋平の誤解は残る。親切な言葉だけでは仕事は進まない。 |
| 数と役割を聞き、各人の断りを尊重する | **条件つきの小さな再試行** | 陽菜と洋平は数字で協力。大輔は工房の返事を延ばし続け、計画から外れる。利益が出るとはまだ言えない。 |
| 人前で嘘つき・無能と断じる | **共同企画は解散** | 訂正はしても陽菜と洋平は離れる。美代子は自分の席を守る。全員がプレイヤーを好くことはない。 |
| 何も言わず見ている | **陽菜だけが規模を縮めて試す** | 美代子と文子は自分たちで話し、掲示を直す。大輔は決めないまま場所を失う。 |
| 手伝うと約束して消え、互いに違う話を伝える | **一度停止し、直接確認する約束を作る** | 人間同士の確認は進むが、プレイヤーの後出し謝罪だけで損なった信頼は戻らない。 |

以上は**紙上の五回の試行**。プログラム実行でも五人の実プレイヤーの反応でもない。四種類の町の結末に分かれ、誰かが変わらない道もある。興味深さは実地で確かめる必要がある。

## 8. 今回止める位置

次に判断すべきことは、事件の数や台詞の量ではなく、**「この六人と30日過ごしたいか。特にもう一度会いたいのは誰で、会いたくないのは誰か」**。今の段階で30日分を書けば、オーナーが興味を持てなかった人物を長く書き直すことになる。承認前に場面、絵、画面、コードには進まない。
