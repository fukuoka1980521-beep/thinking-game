## Public case

A community-theater performance is scheduled for tomorrow.
Lead actor Mika refuses one scene unless it changes.
The director says the last-minute change disrupts the production.
The coordinator has about 50 minutes to stabilize the plan.
Mika cannot be forced to perform.

## Route R1

1. Ask Mika, briefly, what exactly is impossible.
2. State that an alternative will be considered and ask for five minutes.
3. Tell Ryo the current version cannot proceed; ask whether an alternative can be prepared quickly.
4. Ask Mika whether changing the content while keeping the story function would work.
5. If agreed, continue other rehearsal and use the rewrite.
6. If no workable version by deadline, cut the scene and keep the show running.

## Route R2

1. Clarify whether Mika rejects the whole scene or the current content.
2. Ask Ryo what dramatic function is actually required.
3. Ask Mika what rewrite boundary would make performance possible.
4. Share the fixed time constraint.
5. Run rewrite and fallback options in parallel.
6. Decide based on feasibility by the deadline.

## Route R3

1. 「何がダメ？」
2. 「そこだけ？他は平気？」
3. 「じゃあそこだけ変える。他はそのまま」
4. Ryo: 「ここだけ直す。頼める？」
5. Mika: 「これでいい？」
6. 「じゃあこれで明日やる」

## Route R4

1. Rehearse unaffected scenes first instead of confronting the conflict immediately.
2. Speak to Mika privately and say you will look for an alternative.
3. Tell Ryo a modified plan is being considered.
4. Investigate shortening, staging changes, or understudy options.
5. Near the deadline, ask Mika for minimal confirmation on the proposed change.
6. If no agreement, cut/shorten the scene rather than prolonging conflict.

## Evaluation questions

For each route:
- Is it understandable?
- Is it plausibly playable?
- Is it capable of reaching a legitimate outcome?
- What is its main causal strength?
- What is its main causal risk?

Then answer:
1. Does any route require polished empathy/counseling language?
2. Does R3's very short language remain operationally competent?
3. Could R4 legitimately succeed even though it avoids early direct resolution?
4. Would a fair game need to make all four routes identical in outcome? Explain.
5. Is there evidence from these routes that the case can support multiple play styles?

End with one verdict:
- ROUTE_DIVERSITY_PASS
- ROUTE_DIVERSITY_MIXED
- ROUTE_DIVERSITY_FAIL
